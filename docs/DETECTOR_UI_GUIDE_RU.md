# Руководство по графическому интерфейсу детекторов SeeSharp

Документ предназначен для оператора и конечного пользователя модуля. Он
описывает настройку детекторов через браузер без ручного редактирования
`config.json`.

## 1. Открытие интерфейса

Подключите компьютер к той же сети, что и модуль, и откройте:

```text
http://<IP-адрес-модуля>:8081/
```

Для host-версии на этом же компьютере используйте:

```text
http://127.0.0.1:8081/
```

Если страница не открывается, проверьте питание, сетевое подключение, IP-адрес
и наличие запущенного процесса SeeSharp.

## 2. Основные элементы экрана

В верхней части страницы расположены два изображения:

- **Исходное видео** — кадр с камеры без разметки;
- **Результат детекции** — обработанный кадр с найденными объектами;
- **Язык** — переключение русского и английского интерфейса.

Под видео находятся кнопки режимов:

- **Выключено**;
- **ArUco-маркеры**;
- **Объекты YOLO**;
- **Цветовые blobs**;
- **Линии**;
- **Окружности**.

Активный режим выделен зелёным. Одновременно работает только один детектор.
После нажатия кнопки дождитесь сообщения `mode=<имя>`. При ошибке текст причины
появится рядом с кнопками применения настроек.

## 3. Вкладки параметров

### Параметры детектора

Показывает настройки выбранного алгоритма. Флажок **показать все разделы**
открывает параметры всех детекторов, но для обычной работы его включать не
нужно.

### Общие параметры

Настройки применяются к изображению до запуска детектора:

| Параметр | Назначение |
|---|---|
| Поворот камеры | Поворот кадра на `0`, `90`, `180` или `270` градусов |
| Экспозиция | Общее осветление или затемнение изображения |
| Баланс белого | Коэффициенты каналов B, G и R |
| Контрастность | Разница между светлыми и тёмными участками |
| Яркость | Постоянное смещение яркости всех пикселей |

Сначала настройте положение камеры, освещение и общие параметры. Только после
этого калибруйте цветовые и геометрические детекторы.

### Метаданные UART

Для проверки DXL из `uart_dxl_protocol_v21.md` на GPIO14/TX и GPIO15/RX CM5
используйте [инструкцию настройки и проверки DXL](UART_DXL_GPIO_RU.md).
Этот раздел UI настраивает `uart_binary`; DXL включается отдельно в
`transports.uart_dxl`. Не включайте оба транспорта на одном порту.

Содержит настройки бинарной передачи результатов: включение, UART-устройство,
скорость и максимальное количество объектов. Изменяйте их только при
подключённом внешнем контроллере или USB–UART адаптере.

## 4. Применение изменений

В нижней части редактора доступны кнопки:

- **Применить** — немедленно проверить параметры без постоянного сохранения;
- **Сохранить** — применить и записать параметры для последующих запусков;
- **Откатить** — восстановить последнюю сохранённую конфигурацию.

Рекомендуемый порядок:

1. Измените один или два параметра.
2. Нажмите **Применить**.
3. Наблюдайте результат несколько секунд.
4. Если результат устойчив, нажмите **Сохранить**.
5. При ухудшении нажмите **Откатить**.

При наведении указателя на название параметра отображается подсказка. Режим
**редактировать JSON** предназначен для опытных пользователей; синтаксическая
ошибка в JSON не позволит применить конфигурацию.

## 5. Цветовые объекты

Выберите **Цветовые blobs**. Детектор ищет области заданного цвета и формы.

### 5.1. Автоматическое создание цветового шаблона

1. Поместите объект в рабочую зону камеры при обычном освещении.
2. В поле **Номер цветового шаблона** выберите шаблон `0–4`.
3. На **Исходном видео** нажмите кнопку мыши и обведите объект полилинией.
4. Отпустите кнопку — контур автоматически замкнётся.
5. Нажмите **Настроить blob по выделенному контуру**.
6. Нажмите **Применить** и проверьте изображение справа.

В расчёт цвета входят только пиксели внутри выделенного контура. Не захватывайте
фон, блики и тени, не относящиеся к объекту.

### 5.2. Основные параметры цветового шаблона

| Параметр | Как использовать |
|---|---|
| Включено | Позволяет временно отключить отдельный шаблон |
| Нижняя/верхняя граница YCrCb | Допустимый диапазон яркости и цвета |
| Минимальная площадь | Увеличьте, если находится мелкий шум |
| Максимальная площадь | Уменьшите, если фоном считается большая область |
| Минимальная ширина/высота | Отсекает слишком тонкие и мелкие области |
| Округлость | Значение около `1` соответствует кругу |
| Инерция | Низкие значения соответствуют вытянутым объектам |
| Выпуклость | Помогает исключать рваные и вогнутые контуры |
| Количество вершин | Позволяет искать треугольники и многоугольники |

Для первоначальной настройки оставьте геометрические диапазоны широкими.
Сначала добейтесь стабильной цветовой маски, затем по одному включайте
ограничения формы и размера.

### 5.3. Настройка связанного объекта

Связанный объект состоит из 2–5 цветовых частей. В редакторе связанного объекта:

1. Выберите количество частей.
2. Для каждой карточки выберите цветовой шаблон.
3. Нажмите **Выбрать на видео** у первой части.
4. Обведите соответствующий объект на исходном видео.
5. Повторите назначение для остальных частей.
6. Нажмите **Провести связь на видео**.
7. Проведите линию от метки одной части к метке другой.
8. Добавьте остальные необходимые связи.
9. Нажмите **Применить** и перемещайте объект перед камерой.

Связь `0–1` является базовой и не удаляется. Она задаёт основной масштаб и
ориентацию составного объекта. Для устойчивого распознавания используйте только
связи, положение которых действительно сохраняется при движении объекта.

Если части распознаются отдельно, но составной объект не появляется:

- расширьте допустимый диапазон длины связи;
- расширьте допустимый угол;
- уменьшите порог отдельной связи;
- уменьшите общий порог составного объекта;
- убедитесь, что каждой части назначен правильный цветовой шаблон.

## 6. Детекция линий

Выберите **Линии**. На результате должны появиться отрезки поверх выраженных
границ изображения.

Рекомендуемый порядок настройки:

1. Установите область поиска ROI на нужную часть кадра.
2. Настройте нижний и верхний пороги Canny.
3. Задайте минимальную длину линии.
4. Настройте максимальный разрыв между сегментами.
5. Ограничьте минимальный и максимальный угол.
6. Ограничьте максимальное количество линий.

Если линий слишком много, увеличьте пороги Canny и минимальную длину. Если
линии рвутся, увеличьте максимальный разрыв. Для движения робота по линии обычно
достаточно ROI в нижней половине кадра.

## 7. Детекция окружностей

Выберите **Окружности**. Детектор использует границы изображения и преобразование
Хафа.

| Параметр | Рекомендация |
|---|---|
| Минимальный радиус | Чуть меньше минимального ожидаемого круга |
| Максимальный радиус | Чуть больше максимального ожидаемого круга |
| Минимальное расстояние центров | Увеличьте при повторных срабатываниях на одном круге |
| Порог границ | Увеличьте при шумном изображении |
| Порог аккумулятора | Уменьшите для большей чувствительности |

Начинайте с узкого диапазона радиусов. Слишком широкий диапазон заметно
увеличивает нагрузку и количество ложных обнаружений.

## 8. ArUco-маркеры

Выберите **ArUco-маркеры** и укажите:

- словарь, использованный при печати маркеров;
- физическую длину стороны маркера в метрах;
- минимальную и максимальную площадь;
- разрешённые ID, если нужно принимать не все маркеры.

Пустой список разрешённых ID означает отсутствие фильтра. Маркер должен быть
целиком виден, иметь белую рамку и не быть размытым. Если ID не определяется,
сначала проверьте соответствие словаря, затем освещение и фокус камеры.

## 9. Обнаружение объектов YOLO

Выберите **Объекты YOLO**. При первом переключении загрузка модели может занять
несколько секунд. После запуска на результате появляются рамка, название класса
и уверенность.

Основные параметры:

| Параметр | Назначение |
|---|---|
| Файл модели ONNX | Модель для CM5 или host-версии |
| Файл модели RKNN | Модель для MTV3/RV1126 |
| Файл названий классов | Названия классов в порядке выходов модели |
| Ширина/высота входа | Размер входа нейронной сети |
| Порог уверенности | Минимальная вероятность принятого объекта |
| Порог NMS IoU | Подавление пересекающихся рамок одного объекта |
| Максимум объектов | Ограничение числа результатов в кадре |

Если объектов слишком много, увеличьте порог уверенности. Если нужный объект
пропадает, уменьшайте порог небольшими шагами, например по `0.05`. При
дублирующихся рамках уменьшите порог NMS. Не изменяйте формат выхода модели без
информации от разработчика модели.

Низкая частота кадров в YOLO ожидаема на CPU. Для ускорения уменьшите размер
кадра или вход нейросети, используйте аппаратный ускоритель и ограничьте число
объектов.

## 10. Выключенный режим

Режим **Выключено** оставляет захват и веб-видео активными, но не выполняет
детекцию. Используйте его для:

- настройки камеры и освещения;
- проверки видеопотока;
- снижения нагрузки на процессор;
- сравнения исходного и обработанного изображения.

## 11. Как получить устойчивую детекцию

1. Жёстко закрепите камеру.
2. Используйте равномерное освещение без мерцания.
3. Настройте экспозицию и баланс белого до настройки детектора.
4. Ограничьте область поиска и допустимые размеры объектов.
5. Меняйте по одному параметру и проверяйте результат в движении.
6. Проверяйте объект на разных участках кадра и при допустимых расстояниях.
7. После проверки обязательно нажмите **Сохранить**.

Настройка по одному неподвижному кадру недостаточна. Перед сохранением проведите
объект через всю рабочую область и убедитесь, что фон не вызывает ложных
срабатываний.

## 12. Типовые проблемы

| Проблема | Что проверить |
|---|---|
| Исходное видео отсутствует | Камеру, подключение, `/dev/videoN`, состояние процесса |
| Результат не обновляется | Активный режим, сообщение интерфейса, загрузку CPU |
| После переключения написано «Запуск режима…» | Подождать загрузку модели; проверить журнал процесса и файлы YOLO |
| Blob не виден | YCrCb, площадь, ширину, высоту и флаг **Включено** |
| Много ложных blobs | Сузить цвет, увеличить минимальную площадь, добавить фильтр формы |
| Связанный объект не найден | Сначала проверить каждую часть, затем длины, углы и пороги связей |
| ArUco не определяется | Словарь, белую рамку, резкость и видимость всех углов |
| YOLO не запускается | Наличие модели и файла классов, правильность путей и формата модели |
| Видео работает медленно | Уменьшить разрешение/FPS, отключить тяжёлый детектор |
| Изменения исчезли после перезапуска | Использовалась кнопка **Применить**, а не **Сохранить** |

Техническая установка host-версии описана в `docs/HOST_CAMERA_SETUP_RU.md`, а
полный перечень параметров и транспортов — в `docs/USER_GUIDE_RU.md`.
