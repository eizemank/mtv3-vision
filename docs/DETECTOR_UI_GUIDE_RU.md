# Руководство по графическому интерфейсу детекторов SeeSharp

Документ предназначен для оператора и конечного пользователя модуля. Он
описывает настройку детекторов через браузер без ручного редактирования
`config.json`.

## 1. Открытие интерфейса

Подключите компьютер к той же сети, что и модуль, и откройте:

```text
http://<IP-адрес-модуля>:8081/
```

Для host-версии на этом же компьютере используйте:

```text
http://127.0.0.1:8081/
```

Если страница не открывается, проверьте питание, сетевое подключение, IP-адрес
и наличие запущенного процесса SeeSharp.

## 2. Основные элементы экрана

Страница разделена на две колонки. Справа закреплены относительно окна два
изображения — они остаются на экране при прокрутке параметров, поэтому результат
изменения виден сразу:

- **Исходное видео** — кадр с камеры без разметки; на нём обводят объекты;
- **Результат детекции** — обработанный кадр с найденными объектами;
- под видео в режиме **Цветовые blobs** — номер цветового шаблона и кнопка
  **Настроить blob по выделенному контуру**.

Слева — кнопки режимов, вкладки параметров и сам редактор. Кнопки
**Применить**, **Сохранить** и **Откатить** закреплены у нижнего края окна и
не требуют прокрутки. Переключатель **Язык** находится в заголовке страницы и
дублируется параметром **Язык интерфейса** в общих параметрах. На узком экране
(планшет, телефон) видео размещается сверху, параметры — под ним.

Кнопки режимов:

- **Выключено**;
- **ArUco-маркеры**;
- **Объекты YOLO**;
- **Классификация** — нейросеть-классификатор, обученная во вкладке **Обучение**;
- **Цветовые blobs**;
- **Линии**;
- **Окружности**.

Активный режим выделен зелёным. Одновременно работает только один детектор.
После нажатия кнопки дождитесь сообщения `mode=<имя>`. При ошибке текст причины
появится рядом с кнопками применения настроек.

## 3. Вкладки параметров

Вкладок четыре: **Параметры детектора**, **Общие параметры**, **Метаданные
UART** и **Обучение** (описана в разделе 13).

### Параметры детектора

Показывает настройки выбранного алгоритма. Флажок **показать все разделы**
открывает параметры всех детекторов, но для обычной работы его включать не
нужно.

### Общие параметры

Настройки применяются к изображению до запуска детектора:

| Параметр | Назначение |
|---|---|
| Режим обработки | Активный детектор; то же, что кнопки режимов над параметрами |
| Поворот камеры | Поворот кадра на `0`, `90`, `180` или `270` градусов (список) |
| Язык интерфейса | `Русский` или `English` (список); на распознавание не влияет |
| Экспозиция | Общее осветление или затемнение изображения, ступени EV; шаг `0.1` |
| Баланс белого | Коэффициенты каналов B, G и R через запятую; `1, 1, 1` — без изменений |
| Контрастность | Множитель контраста; `1` — без изменений, шаг `0.05` |
| Яркость | Постоянное смещение яркости всех пикселей, `−255…255` |
| Отладочный режим | Дополнительная диагностическая разметка и вывод |

Сначала настройте положение камеры, освещение и общие параметры. Только после
этого калибруйте цветовые и геометрические детекторы.

### Метаданные UART

Для проверки DXL из `uart_dxl_protocol_v21.md` на GPIO14/TX и GPIO15/RX CM5
используйте [инструкцию настройки и проверки DXL](UART_DXL_GPIO_RU.md).
Этот раздел UI настраивает `uart_binary`; DXL включается отдельно в
`transports.uart_dxl`. Не включайте оба транспорта на одном порту.

Содержит настройки бинарной передачи результатов: включение, UART-устройство,
скорость и максимальное количество объектов. Изменяйте их только при
подключённом внешнем контроллере или USB–UART адаптере.

## 4. Применение изменений

В нижней части редактора доступны кнопки:

- **Применить** — немедленно проверить параметры без постоянного сохранения;
- **Сохранить** — применить и записать параметры для последующих запусков;
- **Откатить** — восстановить последнюю сохранённую конфигурацию.

Рекомендуемый порядок:

1. Измените один или два параметра.
2. Нажмите **Применить**.
3. Наблюдайте результат несколько секунд.
4. Если результат устойчив, нажмите **Сохранить**.
5. При ухудшении нажмите **Откатить**.

При наведении указателя на название параметра или на поле ввода отображается
подсказка на языке интерфейса: что означает параметр, на что влияет и в какую
сторону его менять. В конце подсказки указан ключ JSON, по которому параметр
описан в `docs/USER_GUIDE_RU.md`.

Поля ввода трёх видов:

- **список** — для параметров с фиксированным набором значений (размер ядра
  Canny, поворот камеры, словарь ArUco, язык, режим области классификации и
  т. п.). Если в сохранённом конфиге оказалось недопустимое значение, оно
  показано в списке с пометкой «(недопустимо)» — выберите допустимое;
- **число** — стрелки поля меняют значение с шагом, подходящим параметру:
  пороги и доли `0…1` — по `0.01`, углы и пиксели — по `1`. Границы `min/max`
  поля подсказывают допустимый диапазон, но окончательную проверку делает
  программа при применении;
- **текст** — пути, списки через запятую (`1, 1, 1`), имена.

Если значение не прошло проверку, после **Применить** в строке состояния
появится `не применилось: <причина>`, а предыдущие настройки продолжат
действовать. Режим **редактировать JSON** предназначен для опытных
пользователей; синтаксическая ошибка в JSON не позволит применить конфигурацию.

## 5. Цветовые объекты

Выберите **Цветовые blobs**. Детектор ищет области заданного цвета и формы.

### 5.1. Автоматическое создание цветового шаблона

1. Поместите объект в рабочую зону камеры при обычном освещении.
2. В поле **Номер цветового шаблона** выберите шаблон `0–4`.
3. На **Исходном видео** нажмите кнопку мыши и обведите объект полилинией.
4. Отпустите кнопку — контур автоматически замкнётся.
5. Нажмите **Настроить blob по выделенному контуру**.
6. Нажмите **Применить** и проверьте изображение справа.

В расчёт цвета входят только пиксели внутри выделенного контура. Не захватывайте
фон, блики и тени, не относящиеся к объекту.

### 5.2. Основные параметры цветового шаблона

| Параметр | Как использовать |
|---|---|
| Включено | Позволяет временно отключить отдельный шаблон; отключённый цвет не участвует и в связанных объектах |
| Цвет · модель | Цветовая модель (HSL, HSV, RGB, CMYK, HSLuv, YCbCr), палитра, цветовой круг и диапазоны по каналам. Границы проверяются в выбранной модели; при смене модели пересчитываются приближённо |
| Минимум/Максимум по каналам | Допустимый диапазон каждого канала (включительно). Для H минимум больше максимума означает переход через 0° |
| Минимальная площадь, пикс² | Увеличьте, если находится мелкий шум |
| Максимальная площадь, пикс² | Уменьшите, если фоном считается большая область |
| Минимальная ширина/высота, пикс | Отсекает слишком тонкие и мелкие области |
| Минимальная/максимальная округлость, `0…1` | `1` — идеальный круг; `0.6–0.8` оставляет только круглые объекты |
| Минимальная/максимальная инерция, `0…1` | Около `1` — круглые формы, около `0` — вытянутые полосы |
| Минимальная/максимальная выпуклость, `0…1` | Площадь контура к площади выпуклой оболочки; `0.8–0.9` исключает рваные контуры |
| Минимум/максимум вершин | Число вершин после аппроксимации контура; `0` — без ограничения; `3`/`3` — треугольники, `4`/`4` — четырёхугольники |
| Аппроксимация контура | Точность аппроксимации как доля периметра, обычно `0.01–0.05`; меньше — больше вершин |

Для первоначальной настройки оставьте геометрические диапазоны широкими.
Сначала добейтесь стабильной цветовой маски, затем по одному включайте
ограничения формы и размера.

### 5.3. Настройка связанного объекта

Связанный объект состоит из 2–5 цветовых частей. В редакторе связанного объекта:

1. Выберите количество частей.
2. Для каждой карточки выберите цветовой шаблон.
3. Нажмите **Выбрать на видео** у первой части.
4. Обведите соответствующий объект на исходном видео.
5. Повторите назначение для остальных частей.
6. Нажмите **Провести связь на видео**.
7. Проведите линию от метки одной части к метке другой.
8. Добавьте остальные необходимые связи.
9. Нажмите **Применить** и перемещайте объект перед камерой.

Связь `0–1` является базовой и не удаляется. Она задаёт основной масштаб и
ориентацию составного объекта. Для устойчивого распознавания используйте только
связи, положение которых действительно сохраняется при движении объекта.

Если части распознаются отдельно, но составной объект не появляется:

- расширьте допустимый диапазон длины связи;
- расширьте допустимый угол;
- уменьшите порог отдельной связи;
- уменьшите общий порог составного объекта;
- убедитесь, что каждой части назначен правильный цветовой шаблон.

Параметры связанного объекта в разделе **Шаблоны связанных объектов**
(раскрываются для тонкой настройки; редактор выше заполняет их сам):

| Параметр | Что означает |
|---|---|
| Общий порог, `0…1` | Минимальная суммарная оценка для принятия объекта. Уменьшите, если части найдены, а объект нет |
| Способ измерения размера | Что сравнивается как размер компонента: `area` (площадь), `width`, `height`, `max_axis`, `convex_area` |
| Компоненты → ID цветовых шаблонов | Какие цветовые шаблоны могут быть этим компонентом |
| Компоненты → Порог, Вес | Минимальная оценка компонента и его вклад в общую оценку (`0…255`, `0` — не учитывать) |
| Компоненты → Размер / Округлость / Инерция / Выпуклость / Угол | Критерии формы: **Минимум** и **Максимум** задают допустимый интервал, **Целевое значение** получает максимальную оценку, **Вес** — вклад (`0` отключает критерий) |
| Компоненты → Размер | Для базового компонента 0 — в пикселях по выбранному способу измерения; для остальных — отношение к размеру базового (`1` — такой же размер) |
| Связи → Порог, Вес | То же для связи между двумя компонентами |
| Связи → Абсолютная длина, пикс | Допустимое расстояние между компонентами в пикселях |
| Связи → Относительная длина | Расстояние относительно размера базового компонента |
| Связи → Абсолютный угол, градусы | Направление между компонентами в кадре |
| Связи → Относительный угол, градусы | Направление относительно базовой связи 0–1; не зависит от поворота объекта |

### 5.4. «Настроить blob по выделенному контуру» и «Выбрать на видео»

Обе кнопки запускают один и тот же расчёт: по пикселям внутри обведённого
контура вычисляются диапазон цвета, площадь и минимальные ширина/высота
цветового шаблона. Разница — в том, какой шаблон и что ещё меняется:

| | **Настроить blob по выделенному контуру** (под видео) | **Выбрать на видео** (карточка компонента) |
|---|---|---|
| Какой шаблон перенастраивается | Тот, чей номер указан в поле **Номер цветового шаблона** | Тот, что выбран в списке карточки компонента; поле **Номер цветового шаблона** переключается на него |
| Положение на кадре | Не запоминается | Запоминается как метка компонента — нужна для **Провести связь на видео** |
| Когда использовать | Настройка одиночных цветов и режима одноцветной детекции | Настройка частей связанного объекта |

Они не дополняют друг друга, а перезаписывают один и тот же цветовой шаблон:
действует последнее выполненное действие. Если компонент 1 связанного объекта
использует шаблон `1`, а затем нажать **Настроить blob по выделенному контуру** с
номером `1`, компонент 1 будет искать уже новый цвет; его метка на кадре при
этом сохранится. Подсказки с этим же объяснением показываются при наведении на
обе кнопки.

## 6. Детекция линий

Выберите **Линии**. На результате должны появиться отрезки поверх выраженных
границ изображения.

Алгоритм: область поиска → детектор границ Canny → вероятностное
преобразование Хафа → фильтр угла → ограничение числа линий.

| Параметр | Что означает и как менять |
|---|---|
| ROI X / ROI Y, доля кадра | Левый верхний угол области поиска в долях ширины/высоты кадра, `0…1` |
| Ширина / Высота ROI, доля кадра | Размер области поиска в долях кадра, `0…1`. Для движения по линии обычно `ROI Y = 0.5`, `Высота = 0.5` — нижняя половина |
| Нижний порог Canny | Границы слабее этого значения отбрасываются; границы между порогами принимаются, только если соединены с сильными. Увеличьте, если линий слишком много |
| Верхний порог Canny | Границы сильнее этого значения принимаются всегда; обычно в 2–3 раза больше нижнего |
| Размер ядра Canny, пикс | Размер ядра Собеля, только `3`, `5` или `7` (список). `3` — тонкие границы и меньше шума, `7` — грубее, но устойчивее к размытию |
| Точный градиент L2 | Евклидов модуль градиента вместо быстрой суммы; чуть точнее и чуть медленнее |
| Шаг Хафа по расстоянию, пикс | Разрешение накопителя по расстоянию, обычно `1` |
| Шаг Хафа по углу, рад | Разрешение накопителя по углу; `0.01745` = 1° |
| Порог голосов Хафа | Минимальное число точек границы, голосующих за линию. Увеличьте, если линий слишком много |
| Минимальная длина линии, пикс | Отрезки короче отбрасываются; увеличьте, чтобы убрать обрывки |
| Максимальный разрыв линии, пикс | Разрыв между коллинеарными отрезками, который объединяется в одну линию; увеличьте, если линии рвутся |
| Минимальный / максимальный угол, градусы | Допустимая ориентация линии, `−180…180`. Например, `70…110` оставляет вертикальные линии |
| Максимум линий | Сколько линий выводить за кадр после всех фильтров |

Рекомендуемый порядок настройки:

1. Установите область поиска ROI на нужную часть кадра.
2. Настройте нижний и верхний пороги Canny.
3. Задайте минимальную длину линии.
4. Настройте максимальный разрыв между сегментами.
5. Ограничьте минимальный и максимальный угол.
6. Ограничьте максимальное количество линий.

Если линий слишком много, увеличьте пороги Canny, порог голосов и минимальную
длину. Если линии рвутся, увеличьте максимальный разрыв. Недопустимые значения
(размер ядра не из списка, нулевой шаг Хафа, область поиска вне кадра) не
применяются: причина выводится в строке состояния, детектор продолжает работать
со старыми настройками.

## 7. Детекция окружностей

Выберите **Окружности**. Детектор использует границы изображения и преобразование
Хафа.

| Параметр | Рекомендация |
|---|---|
| Минимальный радиус | Чуть меньше минимального ожидаемого круга |
| Максимальный радиус | Чуть больше максимального ожидаемого круга |
| Минимальное расстояние центров | Увеличьте при повторных срабатываниях на одном круге |
| Порог границ | Увеличьте при шумном изображении |
| Порог аккумулятора | Уменьшите для большей чувствительности |

Начинайте с узкого диапазона радиусов. Слишком широкий диапазон заметно
увеличивает нагрузку и количество ложных обнаружений.

## 8. ArUco-маркеры

Выберите **ArUco-маркеры** и укажите:

- словарь, использованный при печати маркеров;
- физическую длину стороны маркера в метрах;
- минимальную и максимальную площадь;
- разрешённые ID, если нужно принимать не все маркеры.

Пустой список разрешённых ID означает отсутствие фильтра. Маркер должен быть
целиком виден, иметь белую рамку и не быть размытым. Если ID не определяется,
сначала проверьте соответствие словаря, затем освещение и фокус камеры.

## 9. Обнаружение объектов YOLO

Выберите **Объекты YOLO**. При первом переключении загрузка модели может занять
несколько секунд. После запуска на результате появляются рамка, название класса
и уверенность.

Основные параметры:

| Параметр | Назначение |
|---|---|
| Файл модели ONNX | Модель для CM5 или host-версии |
| Файл модели RKNN | Модель для MTV3/RV1126 |
| Файл названий классов | Названия классов в порядке выходов модели |
| Ширина/высота входа | Размер входа нейронной сети |
| Порог уверенности, `0…1` | Минимальная вероятность принятого объекта; стрелки поля меняют значение по `0.01` |
| Порог NMS IoU, `0…1` | Подавление пересекающихся рамок одного объекта |
| Максимум объектов | Ограничение числа результатов в кадре |
| Расположение данных выхода | `channels_first` или `channels_last` — формат выходного тензора экспортированной модели |
| Количество атрибутов выхода | Значений на одну рамку: 4 координаты + классы (+1 при objectness) |
| Выход содержит objectness | Для моделей в стиле YOLOv5 с отдельной оценкой объекта |

Если объектов слишком много, увеличьте порог уверенности. Если нужный объект
пропадает, уменьшайте порог небольшими шагами, например по `0.05`. При
дублирующихся рамках уменьшите порог NMS. Не изменяйте формат выхода модели без
информации от разработчика модели.

Низкая частота кадров в YOLO ожидаема на CPU. Для ускорения уменьшите размер
кадра или вход нейросети, используйте аппаратный ускоритель и ограничьте число
объектов.

## 10. Выключенный режим

Режим **Выключено** оставляет захват и веб-видео активными, но не выполняет
детекцию. Используйте его для:

- настройки камеры и освещения;
- проверки видеопотока;
- снижения нагрузки на процессор;
- сравнения исходного и обработанного изображения.

## 11. Как получить устойчивую детекцию

1. Жёстко закрепите камеру.
2. Используйте равномерное освещение без мерцания.
3. Настройте экспозицию и баланс белого до настройки детектора.
4. Ограничьте область поиска и допустимые размеры объектов.
5. Меняйте по одному параметру и проверяйте результат в движении.
6. Проверяйте объект на разных участках кадра и при допустимых расстояниях.
7. После проверки обязательно нажмите **Сохранить**.

Настройка по одному неподвижному кадру недостаточна. Перед сохранением проведите
объект через всю рабочую область и убедитесь, что фон не вызывает ложных
срабатываний.

## 12. Типовые проблемы

| Проблема | Что проверить |
|---|---|
| Исходное видео отсутствует | Камеру, подключение, `/dev/videoN`, состояние процесса |
| Результат не обновляется | Активный режим, сообщение интерфейса, загрузку CPU |
| После переключения написано «Запуск режима…» | Подождать загрузку модели; проверить журнал процесса и файлы YOLO |
| Blob не виден | YCrCb, площадь, ширину, высоту и флаг **Включено** |
| Много ложных blobs | Сузить цвет, увеличить минимальную площадь, добавить фильтр формы |
| Связанный объект не найден | Сначала проверить каждую часть, затем длины, углы и пороги связей |
| ArUco не определяется | Словарь, белую рамку, резкость и видимость всех углов |
| YOLO не запускается | Наличие модели и файла классов, правильность путей и формата модели |
| Видео работает медленно | Уменьшить разрешение/FPS, отключить тяжёлый детектор |
| Изменения исчезли после перезапуска | Использовалась кнопка **Применить**, а не **Сохранить** |
| Во вкладке «Обучение» написано «Тренер недоступен» | Установить venv с PyTorch на устройстве (см. `board/raspberry-cm5/README.md`) или скачать датасет и обучить на ПК |
| После обучения модель путает классы | Активировать модель кнопкой во вкладке (классы берутся из файла модели), не править `class_names` руками; не переименовывать классы после обучения |
| Классификатор работал, а после смены ROI/отступа ухудшился | Съёмка датасета и инференс должны использовать одинаковые `region_mode`, `roi`, `crop_padding`; переснимите примеры |
| Съёмка областей blob отклоняется | Включите режим **Цветовые blobs** (или классификацию с областью blob) перед съёмкой |

## 13. Обучение нейросети

Вкладка **Обучение** замыкает цикл «собрать примеры с камеры → обучить →
включить модель» без работы с файлами. Один экран, сверху вниз:

### 13.1. Область классификации

- **весь кадр** — сеть смотрит на весь кадр целиком; объект должен занимать
  большую его часть;
- **прямоугольник (ROI)** — нажмите **Нарисовать ROI на видео**, протяните
  прямоугольник мышью по исходному видео, затем **Взять ROI из выделения**.
  Оранжевый пунктир показывает действующий ROI. Нажмите **Применить** или
  **Сохранить**;
- **области от blob-детектора** — рамки берутся у включённых одноцветных
  шаблонов blob (можно отметить только нужные). Для съёмки примеров должен быть
  включён режим **Цветовые blobs** — кнопка переключения появится сама.

Строка **Текущий результат** показывает предсказание активного классификатора
(обновляется каждые ~1–2 с).

### 13.2. Классы и примеры

1. Введите имя класса латиницей (`ok`, `defect_1`) и нажмите **Добавить класс**.
   Нужно минимум два класса.
2. Направьте камеру на объект и нажмите **Снимок** (один пример) или
   **Серия N** (N кадров с заданным интервалом). Пример вырезается по выбранной
   области и сохраняется на устройстве; счётчик рядом с классом растёт.
3. Кнопка **Примеры** раскрывает миниатюры: щёлкните неудачные и нажмите
   **Удалить выбранные**.
4. Меняйте ракурс, освещение и фон между сериями — так модель будет устойчивее.
   Для простых задач достаточно 30–100 примеров на класс.

Квоты (размер датасета, примеров на класс, длина серии) задаются в секции
`training` конфига; при их превышении съёмка не запускается, причина выводится
под таблицей.

### 13.3. Обучение на устройстве

Нажмите **Проверить тренер**: интерфейс сообщит, установлен ли PyTorch на
устройстве. Затем задайте число эпох и нажмите **Обучить**. Ниже — полоса
прогресса, точность на обучении и на отложенной части (`val`) и журнал
тренера. Обучение идёт с пониженным приоритетом; на CM5 при этом заметно
проседает FPS видео, это нормально. Кнопка **Остановить** прерывает процесс.

Если тренер недоступен, скачайте датасет ссылкой **Скачать датасет
классификатора (zip)**, обучите на ПК командой из `README.txt` внутри архива и
загрузите полученный ONNX в блоке **Модели**.

### 13.4. Модели

Список моделей с классами, точностью и датой. **Активировать** записывает
модель, её классы и размер входа в конфиг, включает режим **Классификация** с
выбранной областью и сохраняет конфиг. Активная модель отмечена зелёной
точкой. Загрузка своего ONNX: выберите файл, тип (классификатор или YOLO),
при необходимости перечислите классы через запятую и нажмите **Загрузить ONNX**.

Важно: съёмка примеров и распознавание используют одну и ту же вырезку области.
После обучения не меняйте `crop_padding` и способ выбора области — иначе
переснимите датасет.

### 13.5. Разметка YOLO (обучение на ПК)

Для детектора YOLO нужны рамки, и обучение выполняется на компьютере:

1. Перечислите классы через запятую и нажмите **Сохранить классы**.
2. **Снять кадры** сохраняет полные кадры камеры.
3. Выберите кадр из списка — он появится на месте исходного видео. Выберите
   класс рамки, обведите объекты прямоугольниками, нажмите **Сохранить
   разметку**. **Завершить** возвращает живое видео.
4. **Скачать датасет YOLO (zip)** — в архиве `images/`, `labels/`,
   `dataset.yaml` и `README.txt` с командой `train_yolo.py`.
5. Полученный `custom_yolo.onnx` загрузите с типом **YOLO**, указав классы, и
   нажмите **Активировать** — включится режим **Объекты YOLO**.

Техническая установка host-версии описана в `docs/HOST_CAMERA_SETUP_RU.md`, а
полный перечень параметров и транспортов — в `docs/USER_GUIDE_RU.md`.
